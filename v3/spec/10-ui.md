# 10 — UI/UX

## Grundsätze

- **Nur shadcn/ui** (Button, Card, Dialog, Sheet, Drawer, Tabs, Select, Command, Form, Toast/Sonner, Chart, …).
  Keine eigenen Basis-Komponenten, kein Custom-CSS außer Tokens in `index.css`.
- **Mobile-first** (Referenz: iPhone 13 mini bis 15 Pro Max, 375–430 px), Desktop als zweite Spalte/zentrierter Inhalt.
- Dark Mode über Tokens (`system | light | dark`), WCAG-AA-Kontraste, Touch-Ziele ≥ 44 px, sichtbarer Fokus.
- Sprache: Deutsch. Alle Texte in `apps/web/src/i18n/de.ts` (eine Datei, vorbereitet für weitere Sprachen).
- Routing mit React Router (URL-basiert, Deep-Links: `/quick`, `/invite`, `/entry/:id`, `/migrate`). Zurück-Geste funktioniert.
- Jede Ansicht hat Lade-, Leer- und Fehlerzustand. Keine Sackgassen (Lehre aus v2-„Später"-Dialogen, siehe 03).

## Navigation

Untere Leiste mit vier Zielen: **Start** · **Verlauf** · **Auswertung** · **Mehr**. Tagebuch-Umschalter oben
(Name, Icon, Farbe; „Alle" für Verlauf/Auswertung). Neue Einträge über Vorlagen-Kacheln und Schnell-Buttons auf Start (A-133; der Verlauf dient Lesen, Filtern und Export).

## Neuigkeiten und Tutorial (v3.x, M15)

Die Neuigkeiten stehen in `apps/web/src/data/changelog.ts` (pro Version: Datum und 1–6 Punkte auf Deutsch, absteigend sortiert; `APP_VERSION` hat immer einen Eintrag). Die zuletzt gesehene Version liegt im `localStorage` `stb-v3-whatsnew`. Nach einem Update erscheint einmal der Dialog „Neu in Version x“ mit allen ungesehenen Versionen; eine Neuinstallation (Onboarding) zeigt keinen Dialog und setzt die Version. Einstellungen → Über → „Neuigkeiten“ listet alle Versionen.

Die Tour ist eine schlanke eigene Lösung ohne neue Abhängigkeit: eine Karte unten im Bild plus Hervorhebung des Ziels (`data-tour`, `data-[tour-active]:ring-2`), Zustand im `localStorage` `stb-v3-tour`, Schritte in `i18n/de.ts`. Abdeckung: Start, Eintrag, Verlauf, Auswertung, Vorlagen-Editor; Weiter, Überspringen, „Alle überspringen“; Einstellungen → „Tutorial erneut zeigen“. Nur per Tastatur bedienbar; Schritte ohne vorhandenes Ziel werden übersprungen.

## Training (v3.x, M17)

Route `/training`, Kachel „Übungen“ auf Start (die vier Navigationsziele bleiben). Die Seite zeigt die aktuelle Funktionsphase und die passenden Trainingsvorlagen (Spec 05). Ein Durchgang führt Schritt für Schritt durch die Übungen (Timer mit Start und Pause, Stufe, erledigt), am Ende Anstrengung/Schmerz; Speichern ergibt einen normalen Eintrag. Im Vorlagen-Editor: Schalter „Trainingsvorlage“, Funktionsphasen, Konfiguration des Übungsblocks; der Video-Link öffnet extern (`rel=noopener`). Zusätzliche Erinnerung „Übungen“ (eigene Uhrzeit und Tage).
