# 10 — UI/UX

## Grundsätze

- **Nur shadcn/ui** (Button, Card, Dialog, Sheet, Drawer, Tabs, Select, Command, Form, Toast/Sonner, Chart, …).
  Keine eigenen Basis-Komponenten, kein Custom-CSS außer Tokens in `index.css`.
- **Mobile-first** (Referenz: iPhone 13 mini bis 15 Pro Max, 375–430 px), Desktop als zweite Spalte/zentrierter Inhalt.
- Dark Mode über Tokens (`system | light | dark`), WCAG-AA-Kontraste, Touch-Ziele ≥ 44 px, sichtbarer Fokus.
- Sprache: Deutsch. Alle Texte in `apps/web/src/i18n/de.ts` (eine Datei, vorbereitet für weitere Sprachen).
- Routing mit React Router (URL-basiert, Deep-Links: `/quick`, `/invite`, `/entry/:id`, `/migrate`). Zurück-Geste funktioniert.
- Jede Ansicht hat Lade-, Leer- und Fehlerzustand. Keine Sackgassen (Lehre aus v2-„Später"-Dialogen, siehe 03).

## Navigation

Untere Leiste mit vier Zielen: **Start** · **Verlauf** · **Auswertung** · **Mehr**. Tagebuch-Umschalter oben
(Name, Icon, Farbe; „Alle" für Verlauf/Auswertung). Neuer Eintrag über einen festen Button auf Start und Verlauf.

## Ansichten

| Ansicht | Inhalt |
|---|---|
| **Onboarding** | Install-Hinweis (iOS/Android), Modus wählen (Konto / nur dieses Gerät), Passkey bzw. Passwort, Backup-Code (Pflicht, Bestätigung), erstes Tagebuch (Name, Art, Ort für Wetter), Vorlage aus Katalog, Migrationsangebot falls v2-Daten erkannt (11). |
| **Start** | Schnelleintrag (1 Tipp), heutige/letzte Einträge, Sync-Status, Eingang (Kurzbefehl-Items), Banner (Update, Entsperren, Backup-Erinnerung, Konflikte). |
| **Eintrag** | Formular aus Blöcken, `occurredAt`, Tags, Wetter-/GPS-Schalter, Anhänge; Speichern unten fixiert. |
| **Verlauf** | Liste nach Tagen gruppiert, Suche, Filter-Chips, gespeicherte Filter, Eintrag öffnen/bearbeiten/löschen. |
| **Auswertung** | Standard-Ansichten und Periodenvergleich (06), Export-Button. |
| **Mehr → Vorlagen** | Liste mit Drag & Drop, Editor (Block-Palette, Drag & Drop, Rollen, Vorschau), Katalog. |
| **Mehr → Tagebücher** | Anlegen, Reihenfolge, Einstellungen (Name, Zeitzone, Wetter-Ort/-Schalter, GPS-Vorbelegung, Schnelleintrag), Mitglieder & Einladungen (09), Kurzbefehl (08). |
| **Mehr → Export & Backup** | Formate aus 07, Import, Backup. |
| **Mehr → Einstellungen** | Konto, Geräte & Passkeys, Sperre („entsperrt bleiben", Inaktivität), Modus, Darstellung, Erinnerungen, Konfliktprotokoll, Über/Version. |

Jede Zeile dieser Tabelle ist durch mindestens eine Akzeptanz-ID abgedeckt (M14 schließt die Lücken).

## Funktionsparität zu v2 (darf nicht verloren gehen)

| v2 | v3 |
|---|---|
| Tägliche Erinnerungs-Benachrichtigung (`notificationService`) | Einstellungen → Erinnerungen (Uhrzeit, Tage), lokale Notification über den SW |
| Install-Hinweis (`InstallPrompt`) | Onboarding + Banner auf Start (UI-19) |
| Update-Hinweis mit Backup-Angebot (`UpdateBanner`) | Update-Banner (04); Backup-Angebot nur in local-only |
| Persistenter Speicher (`persistentStorage`) | `navigator.storage.persist()` beim Onboarding, Status in Einstellungen |
| Dashboard-Export PNG/PDF | Auswertung → Export (06, 07) |
| Vorlagen-Stile/Icons (`TemplateStylePicker`, Icon-Picker) | Vorlagen-Editor (Icon + Farbe) |
| Tutorial (`TutorialContext`) | Kontextuelle Leerzustände mit Hinweisen; volles Tutorial → v3.x |
| Debug-Panel | Einstellungen → Über → Diagnose (Version, Sync-Status, Outbox, Speicher; ohne Klartextdaten) |

## Human-Gates (der Loop hält an und wartet auf Freigabe)

| Gate | Wann | Was der User bekommt |
|---|---|---|
| **G1 Wireframes** | Ende M6, vor dem ersten UI (M7) | Klickbare Low-Fi-Skizzen der Ansichten oben (als statische HTML-Seiten in `v3/design/`) |
| **G2 Kernablauf** | Ende M8 | Lauffähige App lokal: Onboarding → Eintrag → Verlauf → Schnelleintrag, zum Durchklicken auf dem iPhone |
| **G3 Auswertung & Export** | Ende M11 (nach Migration, damit echte Daten vorliegen) | Auswertung, Vergleich, PDF mit echten (migrierten) Daten |
| **G4 Ablösung** | Ende M13 | Checkliste aus 11 + Freigabe zur Umstellung des Deployments |

Feedback aus den Gates wird in `PROGRESS.md` notiert und vor dem nächsten Meilenstein umgesetzt.
